# Cartouche

Unofficial configurator for the 8BitDo Retro Mechanical Keyboard and Retro R8 mouse: key and button remapping, macros, profiles ("cartridges"), and software-side features (per-app profiles, layers).

Work in progress — nothing usable yet. Not affiliated with 8BitDo. Never flashes firmware.

Protocol knowledge builds on [goncalor/8bitdo-kbd-mapper](https://github.com/goncalor/8bitdo-kbd-mapper), [Aryaman73/8db-retro-config](https://github.com/Aryaman73/8db-retro-config), [KilnerJhow/retro87-configurator](https://github.com/KilnerJhow/retro87-configurator) and [mbs1337/r8-rs](https://github.com/mbs1337/r8-rs).
